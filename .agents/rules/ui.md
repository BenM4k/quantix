# UI Rules

Using shadcn/ui and Tailwind.

## Components

Prefer existing shadcn components.

Extend components instead of duplicating.

## Styling

Use:

Tailwind classes.

Avoid:

inline styles.

## Accessibility

Always include:

- Labels.
- Keyboard support.
- Proper semantic HTML.
- Loading states.
- Error states.

## Forms

Use:

- React Hook Form.
- Zod validation.

Never duplicate validation logic.
